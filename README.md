# Mutual Fund Analytics

## Project Overview
This project analyzes mutual fund industry data using Python, SQL, and Power BI.

## Features
- Data Cleaning
- EDA Analysis
- Performance Analytics
- Investor Analytics
- Risk Metrics
- Dashboard Development
- Fund Recommendation System

## Technologies Used
- Python
- Pandas
- SQLite
- Power BI
- Matplotlib

## Project Structure

data/
notebooks/
reports/
sql/

## How to Run

1. Run data_ingestion.py
2. Run data_cleaning.py
3. Run database_setup.py
4. Open notebooks
5. Open Power BI dashboard

## Deliverables

- EDA Analysis
- Performance Analytics
- Dashboard
- Risk Analytics
- Final Report
